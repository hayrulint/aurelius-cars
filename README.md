# Aurelius Cars

Final project for Web Technologies (Frontend), AITU, group MT-2504.

It is a website of a car showroom in Astana (not a real one) with Porsche, Mercedes-Benz and Audi cars. You can look at the cars, filter them, save the ones you like, book a test drive and make an account.

Live website: https://hayrulint.github.io/aurelius-cars/

## Pages

- index.html - home page
- services.html - catalogue of cars, compare table, services
- about.html - about us and team
- contact.html - test drive form, map, weather, FAQ
- register.html, login.html, profile.html - account
- 404.html - page not found

## What we used

- HTML, CSS (flexbox, grid), JavaScript, jQuery, Bootstrap (only for forms)
- localStorage for users, theme, saved cars and filters
- Open-Meteo API for weather and ExchangeRate-API for prices in KZT and EUR
- Icons from Lucide, brand logos from Simple Icons

## How to run

Just open the live link or download the project and open index.html. Weather, currency and map need internet.

Note: there is no backend, so all accounts and data are saved only in the browser.
